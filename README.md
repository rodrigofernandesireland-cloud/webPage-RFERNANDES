# RFERNANDES Designer Portfolio

Next.js portfolio website for a Dublin-based designer.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Editing the portfolio

Main content and project placeholders are in `app/page.tsx`.

Replace the temporary image URLs with real portfolio images. Local images can be placed in `public/images/` and referenced as `/images/project.jpg`.
